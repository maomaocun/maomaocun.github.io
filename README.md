# Yicun Yang's Academic Homepage

This repository powers [Yicun Yang's personal academic homepage](https://maomaocun.github.io/).

The site presents Yicun's research on discrete diffusion language models, efficient LLM inference, adaptive caching, and efficient AI systems.

## Repository structure

- `_pages/about.md` — homepage content
- `_pages/cv.md` — education, experience, and selected publications
- `_publications/` — publication records and paper links
- `_sass/_custom.scss` — homepage styling
- `_config.yml` — site metadata, profile links, and build settings

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000>.
